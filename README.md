# Paradise Nursery Shopping Application

Paradise Nursery is a React-based e-commerce application for browsing and purchasing houseplants.

## Features

- Attractive landing page with a Get Started button
- Company information section
- Three plant categories with six unique plants each
- Product thumbnails, descriptions, names, and prices
- Add to Cart functionality with disabled buttons for added products
- Shared navigation bar with Home, Plants, and Cart links
- Dynamic shopping cart item count
- Redux Toolkit state management
- Increase and decrease quantity controls
- Remove items from the shopping cart
- Individual item totals and overall cart total
- Checkout placeholder displaying Coming Soon
- Continue Shopping navigation

## Technology Stack

- React
- Redux Toolkit
- React Redux
- React Router
- Vite
- CSS

## Run Locally

1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in the terminal.

## Project Structure

- `src/App.jsx`: Application routes and landing page
- `src/App.css`: Styling and landing page background
- `src/AboutUs.jsx`: Company information
- `src/CartSlice.jsx`: Redux shopping cart state
- `src/ProductList.jsx`: Product listing and categories
- `src/CartItem.jsx`: Shopping cart page
- `src/store.js`: Redux store configuration
- `src/main.jsx`: Application entry point
